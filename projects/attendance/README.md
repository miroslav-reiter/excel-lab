# Projekt – Evidencia dochádzky

## Cieľ

Vytvoríme dochádzkový report s výpočtom odpracovaného času.

## Zdrojové dáta

Použijeme `../../data/attendance.csv`.

## Požiadavky

1. Importujeme dochádzku do Excel Table
2. Vytvoríme stĺpec `WorkedHours`
3. Od odchodu odpočítame príchod a prestávku
4. Výsledok zobrazíme vo formáte `[h]:mm`
5. Vytvoríme súhrn podľa zamestnanca
6. Vypočítame počet dní `Office` a `Remote`
7. Zvýrazníme príchody po 08:15
8. Vytvoríme mesačný súhrn odpracovaného času
9. Skontrolujeme prázdne alebo neplatné časy
10. Pripravíme report na tlač
