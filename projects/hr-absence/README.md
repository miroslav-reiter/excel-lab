# Projekt – HR Absencie

## Cieľ

Vytvoríme analytický model absencií a dochádzky pre HR reporting.

## Zdrojové dáta

Použijeme `../../data/employees.csv` a `../../data/attendance.csv`.

## Požiadavky

1. Prepojíme dochádzku so zoznamom zamestnancov podľa `EmployeeID`
2. Doplníme oddelenie a pracovnú pozíciu
3. Vypočítame odpracovaný čas
4. Označíme chýbajúce alebo neúplné záznamy
5. Vytvoríme súhrn podľa oddelenia
6. Vypočítame pomer práce `Office` a `Remote`
7. Vytvoríme zoznam unikátnych zamestnancov
8. Vytvoríme kontingenčný prehľad podľa oddelenia
9. Vytvoríme graf pracovného režimu
10. Pripravíme dátový výstup vhodný na ďalšiu HR analýzu
