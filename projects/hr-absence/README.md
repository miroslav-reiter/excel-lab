# Projekt – Absencie a dochádzka zamestnancov

## Cieľ

Vytvoríme analytický model absencií a dochádzky pre personálne prehľady.

## Zdrojové dáta

Použijeme `../../data/employees.csv` a `../../data/attendance.csv`.

## Požiadavky

1. Prepojíme dochádzku so zoznamom zamestnancov podľa poľa `ID zamestnanca`
2. Doplníme oddelenie a pracovnú pozíciu
3. Vypočítame odpracovaný čas
4. Označíme chýbajúce alebo neúplné záznamy
5. Vytvoríme súhrn podľa oddelenia
6. Vypočítame pomer práce v režime `Kancelária` a `Na diaľku`
7. Vytvoríme zoznam jedinečných zamestnancov
8. Vytvoríme kontingenčný prehľad podľa oddelenia
9. Vytvoríme graf pracovného režimu
10. Pripravíme dátový výstup vhodný na ďalšiu personálnu analýzu
